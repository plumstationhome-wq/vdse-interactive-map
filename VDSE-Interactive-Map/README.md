# Vista Del Sol Estates Interactive Community Lot Map

This folder is a complete static website for GitHub Pages.

## Upload to GitHub

1. Open the `vdse-interactive-map` repository.
2. Click **Add file** > **Upload files**.
3. Drag all files and folders from this package into the upload area.
4. Click **Commit changes**.
5. GitHub Pages will publish the site from the `main` branch.

Expected URL:
`https://plumstationhome-wq.github.io/vdse-interactive-map/`

## Included

- Search by lot number or address
- Hover/tap property information
- Clickable Google Maps address
- Zoom, pan, and reset controls
- Legend and map disclaimer
- Responsive desktop/mobile layout

## Important accuracy note

Interactive hit areas are aligned to the supplied community map for convenient identification. They are approximate and are not legal parcel boundaries.
